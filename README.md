# chneau.github.io

Personal dashboard and tracker application built with React, Ant Design and Valtio, deployed to GitHub Pages.

## Contents

- Personal dashboard and tool pages
- Web-based save editors for several games
- Small utilities such as birthdays, CV and rail information
- PWA manifest and service worker for offline use

## Run locally

The site is static, so any static file server works:

```bash
npx serve .
```

## Deploy

Push to the default branch; GitHub Pages serves the repository root.
